# Tienda de apps de LogiQD para Umbrel

Para añadirla: en Umbrel, **App Store → ⋯ → Community App Stores**, pegar
`https://github.com/LogiQDAdmin/umbrel-app-store` y abrirla.

| App | |
|---|---|
| [Remote Control](logiqd-claude-rc) | Claude Code en el Umbrel, siempre disponible desde el móvil ([código](https://github.com/LogiQDAdmin/claude-rc)) |
| [IG Automation](logiqd-ig-panel) | Palabras clave por vídeo, DMs y leads de la automatización de Instagram ([código](https://github.com/LogiQDAdmin/ig-panel)) |
